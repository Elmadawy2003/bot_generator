# توثيق ملف المتغيرات (variables.js)

هذا المستند يشرح الغرض من كل متغير في ملف `variables.js` وكيفية تفاعل الواجهة الخلفية معها.

## نقاط النهاية للواجهة البرمجية (API_ENDPOINTS)

يحتوي هذا الكائن على جميع نقاط النهاية المستخدمة للتواصل مع الخادم الخلفي. يتم تنظيمها في مجموعات منطقية لتسهيل الصيانة والتحديث.

### المصادقة (auth)

| النقطة النهائية | الوصف | طريقة الطلب | المعلمات المتوقعة |
|-----------------|-------|------------|-------------------|
| `/api/auth/login` | تسجيل دخول المستخدم | POST | `{ email, password }` |
| `/api/auth/register` | إنشاء حساب جديد | POST | `{ name, email, password }` |
| `/api/auth/logout` | تسجيل خروج المستخدم | POST | - |
| `/api/auth/reset-password` | إعادة تعيين كلمة المرور | POST | `{ email }` |

### البوتات (bots)

| النقطة النهائية | الوصف | طريقة الطلب | المعلمات المتوقعة |
|-----------------|-------|------------|-------------------|
| `/api/bots` | جلب جميع البوتات للمستخدم الحالي | GET | - |
| `/api/bots/create` | إنشاء بوت جديد | POST | `{ name, description, template_id }` |
| `/api/bots/:id` | تحديث بوت موجود | PUT | `{ name, description, settings }` |
| `/api/bots/:id` | حذف بوت | DELETE | - |
| `/api/bots/templates` | جلب قوالب البوتات المتاحة | GET | - |

### المحادثات (conversations)

| النقطة النهائية | الوصف | طريقة الطلب | المعلمات المتوقعة |
|-----------------|-------|------------|-------------------|
| `/api/conversations` | جلب جميع المحادثات | GET | - |
| `/api/conversations/:id` | جلب محادثة محددة | GET | - |
| `/api/conversations/:id` | حذف محادثة | DELETE | - |

### القنوات (channels)

| النقطة النهائية | الوصف | طريقة الطلب | المعلمات المتوقعة |
|-----------------|-------|------------|-------------------|
| `/api/channels/whatsapp` | ربط/تكوين قناة واتساب | POST | `{ phone_number, webhook_url }` |
| `/api/channels/telegram` | ربط/تكوين قناة تيليجرام | POST | `{ bot_token, webhook_url }` |
| `/api/channels/facebook` | ربط/تكوين قناة فيسبوك | POST | `{ page_id, access_token }` |
| `/api/channels/instagram` | ربط/تكوين قناة انستجرام | POST | `{ account_id, access_token }` |
| `/api/channels/voice` | ربط/تكوين قناة المكالمات الصوتية | POST | `{ phone_number, webhook_url }` |

### الاشتراكات (subscriptions)

| النقطة النهائية | الوصف | طريقة الطلب | المعلمات المتوقعة |
|-----------------|-------|------------|-------------------|
| `/api/subscriptions/plans` | جلب خطط الاشتراك المتاحة | GET | - |
| `/api/subscriptions/current` | جلب الاشتراك الحالي للمستخدم | GET | - |
| `/api/subscriptions/upgrade` | ترقية الاشتراك | POST | `{ plan_id, payment_method }` |

## نصوص واجهة المستخدم (UI_TEXT)

يحتوي هذا الكائن على جميع النصوص المستخدمة في واجهة المستخدم. يتم تنظيمها في مجموعات منطقية لتسهيل الترجمة والتخصيص.

### نصوص عامة (general)

تستخدم هذه النصوص في جميع أنحاء التطبيق للرسائل والأزرار الشائعة.

### نصوص المصادقة (auth)

تستخدم هذه النصوص في صفحات تسجيل الدخول وإنشاء الحساب.

### نصوص الصفحة الرئيسية (home)

تستخدم هذه النصوص في الصفحة الرئيسية للموقع.

### نصوص لوحة التحكم (dashboard)

تستخدم هذه النصوص في صفحات لوحة التحكم للمستخدم.

## خصائص المكونات (COMPONENT_PROPS)

يحتوي هذا الكائن على خصائص المكونات المستخدمة في التطبيق. يتم تنظيمها في مجموعات منطقية لتسهيل الصيانة والتحديث.

### روابط شريط التنقل (navbarLinks)

تستخدم هذه الروابط في شريط التنقل العلوي للموقع.

### روابط تذييل الصفحة (footerLinks)

تستخدم هذه الروابط في تذييل الصفحة للموقع.

### خطط الأسعار (pricingPlans)

تستخدم هذه البيانات في صفحة الأسعار لعرض خطط الاشتراك المتاحة.

## بيانات القنوات (CHANNELS_DATA)

يحتوي هذا الكائن على معلومات حول القنوات المختلفة المدعومة في المنصة. يتم استخدام هذه البيانات في صفحات القنوات المختلفة.

## بيانات حالات الاستخدام (USE_CASES_DATA)

يحتوي هذا الكائن على معلومات حول حالات الاستخدام المختلفة للمنصة. يتم استخدام هذه البيانات في صفحات حالات الاستخدام المختلفة.

## ملاحظات للمطورين

1. **التعديل على المتغيرات**: عند إضافة أو تعديل أي متغير في ملف `variables.js`، يجب تحديث هذا المستند أيضًا.

2. **التكامل مع الواجهة الخلفية**: يجب على مطوري الواجهة الخلفية التأكد من أن نقاط النهاية للواجهة البرمجية تتوافق مع المعلمات المتوقعة المذكورة في هذا المستند.

3. **الترجمة**: يمكن إضافة لغات إضافية عن طريق إنشاء نسخ من كائن `UI_TEXT` للغات المختلفة.

4. **التوسع**: عند إضافة ميزات جديدة، يجب إضافة المتغيرات المناسبة إلى الملف والتوثيق.
